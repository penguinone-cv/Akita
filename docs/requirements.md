# Akita 要件定義（初期版）

## 目的と利用範囲

- 家族全員が、家庭内の同じ在庫データをスマートフォンやPCから共有する。
- 初期版は1世帯専用とし、利用者アカウントやログイン機能は設けない。
- 将来、家族用Discordサーバーのアカウントを使うログインへ拡張できる構成にする。

## アイテム

- `＋` ボタンから、名前・カテゴリ・初期在庫数を指定して追加できる。
- アイテムはカードで表示する。
- カード左側の操作で在庫を1減らし、右側の操作で1増やす。
- 在庫数は0未満にできない。
- 編集画面から、名前・カテゴリ・在庫数を直接変更できる。
- アイテムを削除でき、削除後5秒間は取り消せる。
- `±1` と在庫数の直接変更は、操作後5秒間取り消せる。

## カテゴリ

- カテゴリを追加・名称変更・削除できる。
- 「未分類」を最初から用意し、名称変更と削除はできない。
- アイテムが使用中のカテゴリは削除できない。先に別カテゴリを追加してアイテムを移動する。
- 「すべて」とカテゴリごとのタブを表示する。

## 並び順

- カテゴリと、カテゴリ内のアイテムを手動で並べ替えられる。
- 通常操作との誤操作を避けるため、並べ替えは専用モード／管理画面で行う。
- 「未分類」はカテゴリ一覧の末尾に固定する。

## 共有と整合性

- 在庫の正本はサーバー上のPostgreSQLに保存する。
- 別端末の変更をリアルタイムに検知し、表示へ反映する。
- 同時に `＋1` / `−1` しても操作を取りこぼさない。
- 直接入力・編集・並べ替えで古い表示から上書きしようとした場合は競合を検知し、最新状態を読み直す。
- 取り消しは、他端末の在庫変更を消さないよう逆差分として適用する。

## 画面

- モバイルファーストのレスポンシブ表示とし、PCでも利用できる。
- タップ領域を十分に確保し、キーボード操作とスクリーンリーダー向けの名称を用意する。
- 読み込み中、空の一覧、通信エラー、在庫0、同期状態を判別できる。

## 公開環境

- Ubuntu 22.04系のサーバー上でDocker Composeにより動作する。
- アプリはホストの `127.0.0.1:3101` だけに公開する。
- Cloudflareとホスト側リバースプロキシを経由し、`APP_BASE_PATH` で指定したパス（既定値 `/dogs/akita`）で利用する。
- PostgreSQLのポートは外部公開しない。

## 初期版の対象外

- アプリ内アカウント、権限管理、Discordログイン
- 複数世帯の切り替え

認証がない間は、URLへ到達できる利用者が在庫を閲覧・変更できます。公開時の注意事項と任意の入口保護は[デプロイ手順](deployment.md)に記載します。
